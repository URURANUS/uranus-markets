# ⚡ URANUS MARKETS LITE API (v1.2.0)

النسخة الخفيفة، فائقة السرعة والمخصصة للتطبيقات المالية. تركز حصرياً على الأسواق الأساسية المنتقاة مع توفير البيانات الحية والرسوم البيانية (Charts & History) لكل سوق.

---

## 📌 المحتويات الحصرية للنسخة اللايت

1. **الكريبتو (أهم 50 عملة فقط):**
   * قائمة الـ 50 عملة مجمعة بطلب واحد (`/crypto/top50`).
   * أسعار لحظية فردية (`/crypto/price/{pair}`).
   * شموع تاريخية للرسم البياني (`/crypto/history/{pair}`).

2. **البورصات الـ 10 الكبرى ومؤشراتها الرسمية:**
   * 🇲🇦 **المغرب:** بورصة الدار البيضاء كاملة + مؤشر `MASI` + شارت تاريخي.
   * 🇺🇸 **أمريكا:** NYSE & Nasdaq + مؤشرات `S&P 500`, `Dow Jones`, `Nasdaq 100` + شارت.
   * 🇨🇦 **كندا:** تورونتو (TSX) + مؤشر `TSX Composite` + شارت.
   * 🇫🇷 **فرنسا:** باريس + مؤشر `CAC 40` + شارت.
   * 🇩🇪 **ألمانيا:** فرانكفورت + مؤشر `DAX 40` + شارت.
   * 🇬🇧 **بريطانيا:** لندن + مؤشر `FTSE 100` + شارت.
   * 🇳🇱 **هولندا:** أمستردام + مؤشر `AEX` + شارت.
   * 🇪🇸 **إسبانيا:** مدريد + مؤشر `IBEX 35` + شارت.
   * 🇨🇭 **سويسرا:** SIX + مؤشر `SMI` + شارت.
   * 🇮🇹 **إيطاليا:** ميلانو + مؤشر `FTSE MIB` + شارت.

3. **أهم العملات وشارت الصرف عبر الزمان:**
   * 11 عملة أساسية مقابل الدرهم المغربي (`MAD`).
   * تحويل فوري بين العملات (`/fx/convert`).
   * **شارت وتاريخ سعر الصرف** عبر الزمان (`/fx/history?from=USD&to=MAD&range=1mo`).

4. **الذهب والفضة مع الشارت التاريخي:**
   * أسعار حية للأونصة وللجرام (24، 21، 18) بالدولار وبالدرهم.
   * **شارت تاريخي للذهب والفضة** بالشموع (`/metals/history/gold`, `/metals/history/silver`).

## 🚀 قائمة المسارات (Endpoints Table)

| القسم | المسار | الوصف |
| :--- | :--- | :--- |
| **البحث** | `GET /search?q={query}` | **بحث موحد وشامل** في كل الأسواق (كريبتو، أسهم كازا، أسهم عالمية، عملات، معادن) |
| | `GET /crypto/search?q={query}` | بحث مخصص في أهم 50 عملة كريبتو بالاسم أو الرمز |
| | `GET /casablanca/search?q={query}` | بحث مخصص في أسهم بورصة الدار البيضاء بالاسم أو الرمز |
| | `GET /stocks/search?q={query}` | بحث مخصص في الأسهم العالمية والأمريكية |
| **الكريبتو** | `GET /crypto/top50` | جلب الـ 50 عملة كاملة بالترتيب والأسعار في طلب واحد |
| | `GET /crypto/price/{symbol}` | سعر عملة محددة (`BTC`, `ETH`, `SOL`...) |
| | `GET /crypto/history/{symbol}` | شموع تاريخية للكريبتو للشارتات (`interval=1d&limit=30`) |
| **البورصات** | `GET /exchanges` | البورصات الـ 10 مع حالتها الحية (مفتوحة/مغلقة) |
| | `GET /exchange/{slug}/stocks` | أسهم البورصة المحددة (`america`, `france`, `canada`...) |
| **كازا** | `GET /casablanca/stocks` | الـ 74 سهماً لبورصة الدار البيضاء بالدرهم |
| | `GET /casablanca/price/{symbol}` | سعر سهم مغربي (`ATW`, `IAM`, `ADH`...) |
| | `GET /casablanca/history/{symbol}` | نقاط الرسم البياني لأسهم كازا (`days=30`) |
| **المؤشرات** | `GET /indices` | أسعار وتغيرات المؤشرات الـ 12 الرسمية للبورصات المنتقاة |
| | `GET /indices/history/{slug}` | شارت تاريخي لأي مؤشر (`sp500`, `masi`, `cac40`, `dax`...) |
| **الأسهم** | `GET /stocks/price/{symbol}` | السعر اللحظي لأي سهم أمريكي/كندي/أوروبي (`AAPL`, `TSLA`, `MC.PA`) |
| | `GET /stocks/history/{symbol}` | شموع تاريخية لأي سهم أمريكي/كندي/أوروبي للشارت |
| **العملات** | `GET /fx/rates?base=MAD` | أسعار أهم 11 عملة مقابل أي عملة أساس (`MAD`, `EUR`, `USD`...) |
| | `GET /fx/rates/{base}` | جدول أسعار العملات مقابل عملة أساس في المسار (`/fx/rates/EUR`) |
| | `GET /fx/convert` | تحويل مباشر بين العملات (`from=USD&to=MAD&amount=100` أو `from_c`/`to_c`) |
| | `GET /fx/history` | **شارت تاريخ سعر الصرف** (`from=USD&to=MAD&range=1mo`) |
| | `GET /fx/rate-on-date` | **سعر الصرف في تاريخ محدد** لتسجيل الفواتير القديمة (`date=YYYY-MM-DD`) |
| **المعادن** | `GET /metals?currency=MAD` | أسعار الذهب والفضة الحية بالأونصة والجرام بالدولار وبأي عملة |
| | `GET /metals/gold?currency=MAD` | سعر الذهب فقط بالتفصيل |
| | `GET /metals/silver?currency=MAD` | سعر الفضة الحي فقط بالتفصيل |
| | `GET /metals/history/{metal}` | **شارت تاريخ الذهب أو الفضة** بالشموع (`metal=gold`) |
| **تطبيق النفقات** | `GET /sync/rates?base=MAD` | **حزمة مزامنة مضغوطة (~1 KB)** لتخزين العملات والمعادن محلياً (Offline) |
| | `POST /portfolio/value` | **حساب صافي قيمة المحفظة والأصول** بعملة المستخدم بدون حفظ أي بيانات |

## 🛠️ التشغيل المحلي:
```bash
cd URANUS_LITE_SERVER
.\.venv\Scripts\python.exe main.py
```
يعمل محلياً على المنفذ: `http://localhost:8001` (التوثيق: `http://localhost:8001/docs`).
